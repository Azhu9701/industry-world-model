# Origin and Provenance

This file records the public provenance of the evidence-backed, operational WORLD.md specification in this repository.

It is a historical record, not a claim of ownership over the words `WORLD.md` or every use of that filename.

## Origin

The specification grew out of AIMAN.World's Industry World Model work: representing real industries through evidence-backed entities, claims, relations, events, temporal state, review boundaries, and agent-safe actions.

The core design question became:

> What should an unfamiliar agent be able to learn about a real world before it reasons or acts inside it?

That led to a portable Markdown entry point centered on:

```text
Reality
  ↓
Evidence
  ↓
World State
  ↓
Action
  ↓
Verification
  ↓
Reality
```

## What is and is not claimed

This project claims provenance for the specific evidence-backed operational specification developed here.

It does not claim:

- invention of the English word "world";
- exclusive rights to the filename `WORLD.md`;
- priority over every earlier project that used similar naming;
- ownership of independent implementations that merely adopt the convention.

## Related prior work

A separate public project, `jydesign/world.md`, uses the WORLD.md / `.world` naming space for persistent creative-project context and visual canon.

That work is related in spirit but different in scope. This specification focuses on evidence-backed operational worlds, canonical state, uncertainty, action boundaries, and verification against reality.

Interoperability is preferable to namespace competition.

## Attribution

When describing the historical origin of this specification, a concise form is:

> WORLD.md is an open specification initiated through AIMAN.World's Industry World Model work in 2026.

Implementations do not need to brand themselves as AIMAN products to conform.
