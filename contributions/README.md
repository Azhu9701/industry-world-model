# Contributions

This directory is the Git-native intake surface for World Model contributions.

Each contribution lives at:

    contributions/<pack>/<slug>/contribution.json

A contribution may contain new entity identities plus proposed claims, relations, events, and evidence. Incoming factual assertions must remain proposed. Verification and materialization happen after review.

The _example-openbot-x1 directory is synthetic test data used to keep the public contribution contract executable in CI.
